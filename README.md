# RegWatch

Regulatory change monitor with cited answers over UAE regulatory documents (VARA rulebook).

**Status:** work in progress (October 2026).

## Data and copyright
RegWatch downloads public pages from the VARA rulebook for personal, non-commercial research,
as permitted by VARA's Terms of Use. Downloaded content stays in `data/` on my machine and is
never committed to this repository; only code and the list of source links are published.
